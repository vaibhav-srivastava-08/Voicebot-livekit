# Maruti Suzuki Ex-Showroom Price List

All prices below are ex-showroom prices in Indian Rupees. Prices apply to both metallic and non-metallic colours unless a dual-tone price is mentioned separately.

Key terms: MT means manual transmission. AT means automatic transmission. AGS means Auto Gear Shift, which is an automated manual transmission. ISS means Idle Start Stop. ECVT means electronic continuously variable transmission. CNG means compressed natural gas. Smart Hybrid and Strong Hybrid are Maruti's hybrid technologies. Four WD means four wheel drive.
